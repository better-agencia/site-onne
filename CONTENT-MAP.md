# Mapa de conteúdo do site ONNE

Este arquivo é uma referência rápida para pedir alterações. O **modo dev** (`npm run dev`) mostra o mesmo mapa ao vivo, com os números das seções e imagens.

## Como pedir uma alteração

Use o número ou, de preferência, o nome/ID da seção. Exemplos:

```text
Na página /agricultura/, seção 4 (#agras), troque o texto do título para "...".
Na página /agricultura/, imagem 12, troque por /assets/img/modelos/novo.webp.
```

No modo dev, clique no texto ou na imagem para copiar uma referência completa.
